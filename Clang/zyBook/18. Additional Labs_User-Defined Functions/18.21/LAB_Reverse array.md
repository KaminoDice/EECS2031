# 18.21 LAB: Reverse array

Complete the ReverseArray() function that has three parameters: the array size and two integer arrays. Function ReverseArray() should fill the second array with the elements of the first array in reverse order and return the number of elements in the second array.

Ex: If the elements of the input array are 2, 4, and 6, then the elements of the second array should be 6, 4, and 2, and the function should return 3.
