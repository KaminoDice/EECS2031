# 18.22 LAB: Remove all even numbers from an array

Complete the RemoveEvens() function that has three parameters: the array size and two integer arrays. Function RemoveEvens() should fill the second array with the odd elements of the first array and return the number of elements in the second array.

Ex: If the elements of the input array are 1, 2, 3, 4, 5, 6, 7, 8, 9 then RemoveEvens() should return 5, and the elements of the second array should be 1, 3, 5, 7, and 9.
